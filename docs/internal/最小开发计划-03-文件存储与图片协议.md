## 4. ImageStore

新增 `src/main/services/image-store.ts`：

```ts
export class ImageStore {
  constructor(directory: string);

  async write(id: string, bytes: Uint8Array): Promise<string>;
  async read(fileName: string): Promise<Uint8Array | null>;
  async remove(fileName: string): Promise<void>;
  async clear(): Promise<void>;
  async stat(fileName: string): Promise<Stats | null>;
  createReadStream(fileName: string): ReadStream;
  async listFileNames(): Promise<{ name: string; mtimeMs: number }[]>;
  pathFor(fileName: string): string;
}
```

### 4.1 规则

- 目录：`<userData>/images/`。
- 文件名：`<uuid>.webp`；本步只接受 WebP。
- 写入：
  1. `mkdir(directory, { recursive: true })`；
  2. 写 `<uuid>.tmp`；
  3. `rename` 到 `<uuid>.webp`；
  4. 失败清理临时/目标文件并抛错。
- 读取：
  - `read`：返回 `Uint8Array | null`（ENOENT → null）；
  - `createReadStream`：给协议用；
  - `stat`：给协议 `Content-Length` 用。
- 路径安全：
  - `path.resolve(directory, fileName)` 必须仍在目录下；
  - `fileName` 必须是 basename，不允许 `/`、`..`。
- `listFileNames`：返回 `.tmp-*` 在内，后续清理服务自己过滤。
- `clear`：递归删除目录（不存在不报错）。
- 测试可注入临时目录。

## 5. tap-image 协议

新增 `src/main/services/tap-image-protocol.ts`：

```ts
export const TAP_IMAGE_SCHEME = 'tap-image';

export const registerTapImageScheme = (): void;
export const createTapImageResponse = async (
  requestUrl: string,
  images: Pick<PageImagesRepository, 'find'>,
  store: Pick<ImageStore, 'stat' | 'createReadStream'>,
): Promise<Response>;
export const registerTapImageHandler = (
  protocol: { handle: (scheme: string, handler: ...) => void },
  images: ...,
  store: ...,
): void;
```

### 5.1 URL

```text
tap-image://img/<uuid>
```

- host 必须是 `img`；
- pathname 去掉前导 `/` 后必须是 UUID；
- 其它 → 404。

### 5.2 响应

- id 查不到 / 文件不存在 → 404。
- 成功：
  - `Content-Type: image/webp`
  - `Content-Length: stats.size`
  - `Cache-Control: private, max-age=31536000, immutable`
  - `X-Content-Type-Options: nosniff`
  - body：`Readable.toWeb(store.createReadStream(fileName))`。
- 图片内容不可变，允许长缓存。

### 5.3 注册

- `registerTapImageScheme()` 必须在 `app.ready` 之前调用：
  ```ts
  protocol.registerSchemesAsPrivileged([
    {
      scheme: 'tap-image',
      privileges: {
        standard: true,
        secure: true,
        supportFetchAPI: true,
        stream: true,
      },
    },
  ]);
  ```
- `registerTapImageHandler(protocol, images, store)` 在数据库初始化后、创建窗口前调用。

## 6. 图片 IPC

### 6.1 共享契约

扩展 `src/shared/images.ts`：

```ts
export const IMAGE_CHANNELS = {
  create: 'images:create',
  remove: 'images:remove',
} as const;

export interface CreatePageImagePayload {
  bytes: Uint8Array;
}

export interface CreatePageImageResult {
  ok: boolean;
  image?: PageImageMeta;
  errorCode?: AppErrorCode;
}

export interface RemovePageImageResult {
  ok: boolean;
  errorCode?: AppErrorCode;
}

export interface ImageBridge {
  createPageImage?: (
    payload: CreatePageImagePayload,
  ) => Promise<CreatePageImageResult>;
  removePageImage?: (imageId: string) => Promise<RemovePageImageResult>;
}
```

- `TapAlongBridge` extends `ImageBridge`。
- 本步只接受 WebP；payload 不带 mime（避免 renderer 骗主进程）。

### 6.2 images:create

新增 `src/main/ipc/images.ts`：

1. payload 必须是对象；
2. `bytes` 必须是 `Uint8Array` / `ArrayBuffer`，转成 `Uint8Array`；
3. 非空；
4. 检查 WebP magic：
   - 长度 ≥ 12；
   - bytes 0–3 `RIFF`；
   - bytes 8–11 `WEBP`；
5. `randomUUID()` 生成 id；
6. `imageStore.write(id, bytes)` → `<id>.webp`；
7. `images.create({ id, fileName, mime: 'image/webp', byteLength, createdAt: Date.now() })`；
8. DB 失败 → `imageStore.remove(fileName)`，返回 `IMAGE_SAVE_FAILED`；
9. 返回 `{ ok: true, image: { id, mime, byteLength } }`。

- 没有数量/大小上限；只校验格式与结构。
- 失败错误码：
  - 结构/格式 → `IMAGE_INVALID`；
  - 写文件/写库 → `IMAGE_SAVE_FAILED`。

### 6.3 images:remove

1. id 必须是字符串且非空；非法 → `{ ok:false, errorCode:'IMAGE_INVALID' }`；
2. `images.removeIfUnreferenced(id)`；
3. 返回文件名 → `imageStore.remove(fileName)`；
4. 文件删除失败只打日志，最终返回 `{ ok:true }`（幂等，清理服务兜底）；
5. 被引用/不存在 → 返回 null，仍返回 `{ ok:true }`。

### 6.4 preload

`src/preload.ts` 增加：

```ts
createPageImage: (payload) =>
  ipcRenderer.invoke(IMAGE_CHANNELS.create, payload),
removePageImage: (imageId) =>
  ipcRenderer.invoke(IMAGE_CHANNELS.remove, imageId),
```

## 12. 风险与边界

| 风险                    | 影响          | 处理                                                          |
| ----------------------- | ------------- | ------------------------------------------------------------- |
| 协议注册时机            | 图片加载失败  | scheme 在 ready 前注册；handler 在窗口前注册                  |
| 文件写入与 DB 不一致    | 孤儿文件/空行 | 先写文件再写 DB；DB 失败删文件；清理服务兜底                  |
| 路径穿越                | 读取任意文件  | basename 校验 + resolve 前缀校验                              |
| 大文件读入内存          | 主进程卡顿    | 本步接受 WebP；D4 压缩；协议流式读取                          |
| 删除被引用图片          | 其他念头破图  | `removeIfUnreferenced` 只删无引用                             |
| 文件删除失败            | 磁盘残留      | 只打日志；D7 清理                                             |
| 现有测试                | 回归          | 只新增文件/IPC；旧路径不变                                    |
| happy-dom/Node 协议差异 | 测试覆盖不足  | 协议测试用真实临时文件 + `Response`；Electron 注册在 E2E 验证 |
