**本步定位：** 把图片作为上下文发给模型：Prompt 带 imageIds，Gateway 转成 OpenAI 兼容的 `image_url` parts；发送前做真实图片能力检测，不支持/未知自动降级纯文本，绝不因图片中断老师回答。

---

## 1. 这一步要解决什么

D5–D7 已经完成图片保存、显示、导出、清理，但模型仍只看到文字。

本步建立：

```text
当前页 doc → collectNoteImageIds
  → Prompt 消息带 imageIds
  → ImageContextService 读文件转 data URL
  → Gateway 转 [{type:'text'}, {type:'image_url'}]
  → 发送前 ImageCapabilityService 探测/缓存
  → supported：发图；unsupported/unknown：纯文本继续
```

## 5. ImageContextService

新增 `src/main/services/image-context.ts`：

```ts
export interface ChatImageData {
  mime: string;
  dataUrl: string;
}

export interface ImageContextResolver {
  resolve(imageId: string): Promise<ChatImageData | null>;
}

export class ImageContextService implements ImageContextResolver {
  private readonly images: Pick<PageImagesRepository, 'find'>;
  private readonly store: Pick<ImageStore, 'read'>;

  constructor(
    images: Pick<PageImagesRepository, 'find'>,
    store: Pick<ImageStore, 'read'>,
  ) {
    this.images = images;
    this.store = store;
  }

  async resolve(imageId: string): Promise<ChatImageData | null> {
    const row = this.images.find(imageId);

    if (!row) {
      return null;
    }

    const bytes = await this.store.read(row.file_name);

    if (!bytes) {
      return null;
    }

    return {
      mime: row.mime,
      dataUrl: `data:${row.mime};base64,${Buffer.from(bytes).toString('base64')}`,
    };
  }
}
```

- 不设大小/数量上限（上传已压缩）。
- 文件缺失返回 null；gateway 用文本占位。
- 同请求内按 imageId 去重，避免重复 base64。
- 不做跨请求缓存，避免大图长期占内存。

## 6. ModelGateway

### 6.1 类型

`src/main/services/model-gateway.ts`：

```ts
export interface ModelGatewayOptions {
  configService: Pick<ProviderConfigService, 'resolveActive'>;
  inspector?: RequestInspector;
  images?: ImageContextResolver;
  capabilities?: ImageCapabilityResolver;
  fetchImpl?: FetchLike;
  timeoutMs?: number;
}

export interface ImageCapabilityResolver {
  supportsActive(): Promise<boolean>;
}

type ProviderContentPart =
  | { type: 'text'; text: string }
  | { type: 'image_url'; image_url: { url: string } };

interface ProviderMessage {
  role: ChatRole;
  content: string | ProviderContentPart[];
}
```

### 6.2 发送前

```ts
const buildProviderMessages = async (
  messages: ChatMessage[],
  images: ImageContextResolver | undefined,
  capability: ImageCapabilityResolver | undefined,
): Promise<ProviderMessage[]> => {
  const hasImages = messages.some(
    (message) => message.role === 'user' && message.imageIds?.length,
  );
  const supportsImages = hasImages
    ? ((await capability?.supportsActive()) ?? false)
    : false;

  const cache = new Map<string, Promise<ChatImageData | null>>();
  const resolve = (imageId: string) => {
    let pending = cache.get(imageId);
    if (!pending) {
      pending = images?.resolve(imageId) ?? Promise.resolve(null);
      cache.set(imageId, pending);
    }
    return pending;
  };

  const result: ProviderMessage[] = [];

  for (const message of messages) {
    if (message.imageContext && !supportsImages) {
      continue; // 能力不支持时整条附加图片消息丢弃
    }

    if (message.role !== 'user' || !message.imageIds?.length) {
      result.push({ role: message.role, content: message.content });
      continue;
    }

    if (!supportsImages) {
      result.push({ role: message.role, content: message.content });
      continue;
    }

    const parts: ProviderContentPart[] = [
      { type: 'text', text: message.content },
    ];

    for (const imageId of [...new Set(message.imageIds)]) {
      const image = await resolve(imageId);

      if (!image) {
        parts.push({ type: 'text', text: '[image unavailable]' });
        continue;
      }

      parts.push({
        type: 'image_url',
        image_url: { url: image.dataUrl },
      });
    }

    result.push({ role: message.role, content: parts });
  }

  return result;
};
```

- `hasImages` 为 false 时不调用能力检测。
- 能力 `unsupported/unknown`：所有图片降级纯文本；`imageContext` 消息整条丢弃，避免模型看到“附图”却没有图。
- 图片缺失：保留文本占位，不阻断整次请求。
- 同 imageId 只 resolve 一次。
- 探测/图片读取失败不能让主请求失败。

### 6.3 请求体

OpenAI 兼容：

```json
{
  "messages": [
    {
      "role": "user",
      "content": [
        { "type": "text", "text": "当前念头正文" },
        {
          "type": "image_url",
          "image_url": { "url": "data:image/webp;base64,..." }
        }
      ]
    }
  ]
}
```

- 纯文本请求仍用字符串 content，保持旧行为。
- 图片 data URL 只存在于实际请求体；不写入 inspector。

### 6.4 inspector 脱敏

- `RequestInspector` 记录 messages 时，把多模态 content 转成文本：
  - image parts → `[image]`；
  - 不存 data URL/base64。
- 现有文本请求记录不变。

## 7. 图片能力检测

新增 `src/main/services/image-capability.ts`：

### 7.1 类型

```ts
export type ImageInputMode = 'auto' | 'off';
export type ImageCapabilityStatus = 'supported' | 'unsupported' | 'unknown';

export interface ImageCapabilityDecision {
  supported: boolean;
  status: ImageCapabilityStatus;
  source: 'override' | 'cache' | 'probe' | 'unknown';
}
```

- 与 `src/shared/providers.ts` 的 UI 类型保持一致；D9 再把状态暴露给设置页。

### 7.2 探测

- 内置 64×64 WebP（base64 常量）。
- 请求：
  - 当前 provider/model；
  - `max_tokens: 1`；
  - 一条 user 消息，含 text + image_url（与真实请求同格式）；
  - 超时 8s；
  - 不写开发者请求记录；
  - 不发用户图片。
- 结果映射：
  - 2xx → supported；
  - 400 / 415 / 422 → unsupported；
  - 401 / 403 / 404 → unsupported；
  - 429 / 网络错误 / 超时 → unknown；
  - 其它 5xx → unknown。
- 探测请求本身失败不影响主流程。

### 7.3 缓存与并发

- key：providerId + model + baseUrl（避开同一供应商不同代理）。
- TTL：7 天。
- 内存缓存 + in-flight promise；并发只探测一次。
- `imageInput === 'off'` → unsupported（override）。
- `unknown` 本次按 unsupported 处理，但缓存短 TTL（如 10 分钟），稍后重试。
- 缓存持久化到 electron-store 放到 D9；本步先内存。

### 7.4 接口

```ts
export interface ImageCapabilityResolver {
  supportsActive(): Promise<boolean>;
}

export class ImageCapabilityService implements ImageCapabilityResolver {
  constructor(
    configService: Pick<ProviderConfigService, 'resolveActive'>,
    dependencies: {
      fetchImpl?: FetchLike;
      now?: () => number;
      cacheTtlMs?: number;
      timeoutMs?: number;
    } = {},
  ) {}

  supportsActive(): Promise<boolean>;
}
```

- 只在 `buildProviderMessages` 检测到 imageIds 时调用。
- 纯文本请求不探测。

## 12. 风险与边界

| 风险              | 影响                   | 处理                                         |
| ----------------- | ---------------------- | -------------------------------------------- |
| 供应商不支持图片  | 请求中断               | 发送前探测；unsupported/unknown 纯文本       |
| 探测误判          | 支持图片的供应商被跳过 | 7 天缓存 + D9 手动重新检测；不强制发送       |
| 多模态格式不兼容  | 4xx                    | 使用 OpenAI 兼容 image_url；探测与实际同格式 |
| data URL 进入日志 | 隐私/膨胀              | inspector 脱敏；只在实际请求体               |
| 大图请求体        | 超时/超限              | 上传已压 2400/0.9；不额外限制                |
| 图片读取失败      | 请求失败               | 文本占位 `[image unavailable]`               |
| 并发探测          | 多次请求               | in-flight 共用                               |
| 能力缓存过期      | 不发送                 | 7 天；D9 手动重测                            |
| 旧纯文本测试      | 回归                   | content 字符串路径保持；默认无图不探测       |
