**编号：** MINI-IMAGE-06

**状态：** 已实现（待验收）

**依据：** [技术方案-笔记图片粘贴.md](../design/技术方案-笔记图片粘贴.md)（v5）、[开发计划-笔记图片粘贴.md](开发计划-笔记图片粘贴.md)、[最小开发计划-05-图片节点与粘贴上传.md](最小开发计划-05-图片节点与粘贴上传.md)（已完成）

**本步定位：** 把“只能在编辑态看到图片”补成完整阅读体验：卡片保留两行摘要 + 含图标记 + 查看全文；全文浮层只读展示富文本和图片；图片可点开 Lightbox。**本步不加新编辑能力。**

---

## 1. 这一步要解决什么

D5 之后：

- 编辑态可以粘图，保存 `body_doc` + `page_image_refs`；
- 卡片仍只显示两行 `body`，读模式看不到图片；
- 没有全文浮层，也没有图片放大。

本步要补齐：

```text
卡片两行摘要
  + “含 N 张图”标记
  + “查看全文”
      → 只读全文浮层（文字 + inline 图片）
      → 点图片 → Lightbox
```

完成后，用户保存含图念头后，不进入编辑也能完整回看图文。

## 4. NoteDocView

新增 `src/components/note/NoteDocView.vue`：

```ts
defineProps<{
  doc: NoteDoc;
}>();

defineEmits<{
  'image-click': [imageId: string, alt: string];
}>();
```

### 4.1 渲染

```vue
<div class="note-doc">
  <p v-for="(paragraph, index) in doc.content" :key="index" class="note-doc__p">
    <template v-for="(inline, inlineIndex) in paragraph.content ?? []">
      <span v-if="inline.type === 'text'">{{ inline.text }}</span>
      <br v-else-if="inline.type === 'hardBreak'" />
      <button
        v-else
        type="button"
        class="note-doc__image-button"
        :aria-label="t('companion.viewImage')"
        @click="emit('image-click', inline.attrs.imageId, inline.attrs.alt ?? '')"
      >
        <img
          class="note-doc__image"
          :src="`tap-image://img/${inline.attrs.imageId}`"
          :alt="inline.attrs.alt ?? ''"
        />
      </button>
    </template>
  </p>
</div>
```

- 空段落 `p` 保留高度（`min-height: 1.75em`）。
- 图片 `max-width: 100%; height: auto; border-radius: 10px;`。
- 不裁剪；不固定宽高。
- 文本 `white-space: pre-wrap; word-break: break-word;`。
- 图片按钮无默认样式，焦点可见。
- 不渲染 marks（本步 schema 没有 marks）。

### 4.2 为什么不用 TipTap 只读实例

- 只读展示不需要 ProseMirror 状态/插件/编辑器生命周期。
- 小 doc 直接 Vue 渲染更轻，避免每个卡片再起一个 editor。
- 编辑态仍用 `NoteEditor`；两套渲染共享 `NoteDoc`。

## 6. PageCardFullText

新增 `src/components/companion/PageCardFullText.vue`：

```ts
props: {
  title: string;
  doc: NoteDoc;
};

emits: {
  close: [];
  'image-click': [imageId: string, alt: string];
};
```

### 6.1 结构

```vue
<Teleport to="body">
  <div class="full-text" role="presentation" @mousedown.self="emit('close')">
    <section
      class="full-text__panel"
      role="dialog"
      aria-modal="true"
      aria-labelledby="full-text-title"
    >
      <header class="full-text__header">
        <h2 id="full-text-title">{{ title }}</h2>
        <button ref="closeButton" type="button" @click="emit('close')">
          {{ t('companion.closeFullText') }}
        </button>
      </header>

      <div class="full-text__body">
        <NoteDocView :doc="doc" @image-click="..." />
      </div>
    </section>
  </div>
</Teleport>
```

### 6.2 行为

- 打开：
  - 记录 `document.activeElement`；
  - `document.body.style.overflow = 'hidden'`；
  - `nextTick` 后 focus 关闭按钮。
- 关闭/卸载：
  - 恢复 body overflow；
  - 焦点还原到打开前的元素。
- `keydown`：
  - Escape → close；
  - 可选简单 Tab 循环（焦点不跑出面板）。
- 背景点击用 `@mousedown.self`，避免从面板内拖到背景误关。
- 面板最大宽度约 720px，最大高度 `min(86vh, 900px)`；`full-text__body` 内部滚动。
- 移动端全宽，底部留 safe-area。

## 8. PageCard 接线

`PageCard.vue`：

```ts
const props = defineProps<{
  page: PageRecord;
  canGenerateTitle?: boolean;
  canEditTitle?: boolean;
}>();

const fullTextOpen = ref(false);
const lightboxImage = ref<{ src: string; alt: string } | null>(null);
const readerDoc = computed(
  () => props.page.doc ?? docFromPlainText(props.page.body),
);
const imageCount = computed(() => countNoteImages(readerDoc.value));
```

模板：

```vue
<PageCardSummary
  v-if="!page.editing"
  :body="page.body"
  :image-count="imageCount"
  @open-full-text="fullTextOpen = true"
/>

<PageCardFullText
  v-if="fullTextOpen"
  :title="page.title"
  :doc="readerDoc"
  @close="fullTextOpen = false"
  @image-click="
    (imageId, alt) => {
      lightboxImage = {
        src: `tap-image://img/${imageId}`,
        alt,
      };
    }
  "
/>

<ImageLightbox
  v-if="lightboxImage"
  :src="lightboxImage.src"
  :alt="lightboxImage.alt"
  @close="lightboxImage = null"
/>
```

- 编辑态不显示摘要/全文按钮。
- 全文打开时点图片 → 灯箱叠在全文上；关灯箱回到全文。
- 全文关闭时同时清空 `lightboxImage`，避免孤儿层。
