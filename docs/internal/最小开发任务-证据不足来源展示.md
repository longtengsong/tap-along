# 最小开发任务 · 证据不足时的来源展示

**任务编号：** MINI-RESEARCH-SOURCES-001

**状态：** 待确认

**估时：** 1.5 人日（单人，含单测与回归）

**新增依赖：** 无

---

## 1. 一句话目标

当联网检索**找到了一些结果，但来源不足以支撑结论**时，不要只弹一句“没有找到可靠来源”：

- 保留检索到的来源；
- 用一句固定说明告诉用户“这些资料不足以下结论，仅供核对”；
- 在下方列出可点开的来源；
- 仍然不生成模型断言式回答。

这样既坚持“证据不足不硬答”，也不把已经找到的资料直接丢掉。

---

## 2. 本任务做什么、不做什么

### 2.1 做

- `WebSearchService` 在 `RESEARCH_NO_EVIDENCE` 时携带已排序的来源。
- `TeacherService` 捕获这个错误，不调用回答模型，直接写入一条固定文案 + 来源。
- 固定文案跟随用户提问语言。
- 来源列表复用现有 `SourceList`，可点开、可持久化。
- 刷新/重启后，这条“证据不足”消息和来源仍在。
- 新增 `citationStatus: 'insufficient'`，避免 UI 误显示“这段回答没有标注来源”。
- 不增加教学轮次；不触发“建议合上”。

### 2.2 不做

- 不做“带警告的回答”。
- 不做网页全文抓取。
- 不做搜索重试 / 换词重搜。
- 不做来源质量解释面板。
- 不改搜索供应商、设置、来源分级策略。
- 不改正常有证据回答的行为。
- 不改 `SEARCH_NO_RESULTS`（真正没搜到）的现有错误提示。
- 不改 `SEARCH_NOT_CONFIGURED` / `SEARCH_DISABLED` 的现有提示。

## 3. 当前行为与目标行为

### 3.1 当前行为

```text
检索返回若干结果
  → 来源分级后只有 general / ugc
  → isEvidenceSufficient = false
  → 抛 RESEARCH_NO_EVIDENCE
  → 现有 overlay：“没有找到足够可靠的来源，这次先不往下答。”
  → 结果全部丢弃
```

问题：用户看不到到底搜到了什么，也无法自己核对。

### 3.2 目标行为

```text
检索返回若干结果
  → 只有 general / ugc
  → 不调用回答模型
  → 写入一条老师消息：
       “找到了一些资料，但来源不够可靠，这次先不据此下结论。
        你可以点开来源自己核对。”
  → 下方列出 1–5 条来源
  → 用户可点开
```

真正的“0 条结果”仍然走现有 `SEARCH_NO_RESULTS` overlay，不产生空消息。

## 4. 最小技术方案

### 4.1 `SearchError` 携带证据

```ts
export class SearchError extends Error {
  readonly errorCode: AppErrorCode;
  readonly evidence?: ResearchEvidence[];
}
```

- `WebSearchService.search` 先完成排序和 evidence 映射，再做充分性判断：

```ts
const evidence = ranked.map(...);

if (!isEvidenceSufficient(ranked)) {
  throw new SearchError('RESEARCH_NO_EVIDENCE', evidence);
}

return evidence;
```

- `SEARCH_NO_RESULTS` 仍不带 evidence。
- 现有测试只断言错误码，新增断言 `error.evidence.length > 0`。

### 4.2 `TeacherService` 的证据不足分支

在 `streamResearch` 的 catch 中：

```ts
if (
  error instanceof SearchError &&
  error.errorCode === 'RESEARCH_NO_EVIDENCE' &&
  error.evidence?.length
) {
  return this.streamInsufficientEvidence(
    page,
    input,
    error.evidence,
    emit,
    signal,
  );
}
```

`streamInsufficientEvidence`：

1. 用 `resolveMockReplyLanguage` 决定语言。
2. 固定文案：

```ts
translateFixedMessage(replyLanguage, 'teacherFallback.researchInsufficient');
```

3. `sources = evidence.map((item) => item.source)`。
4. `completeResearchAnswer(page.id, text, sources, requestId, 'insufficient')`。
5. `done`：

```ts
{
  ok: true,
  mode: 'answer',
  reply: text,
  sources,
  citationStatus: 'insufficient',
  suggestClose: false,
}
```

- 不调用 `this.generate`，不花回答模型的 token。
- 写入失败、页面关闭、取消时仍走原有错误/取消逻辑。

### 4.3 持久化 `citationStatus`

`completeResearchAnswer` 增加可选参数：

```ts
citationStatus: 'cited' | 'uncited' | 'insufficient' = 'cited'
```

- 正常回答传 `citation.citationStatus`；
- 证据不足传 `'insufficient'`；
- 写入 `PageMessageSnapshot.citationStatus`。

`PageMessageSnapshot` 增加：

```ts
citationStatus?: 'cited' | 'uncited' | 'insufficient';
```

- `parseMessages` 只接受这三个值。
- `toPageRecord` 优先透传；旧消息没有该字段时，仍按“有 `[n]` 即 cited，否则 uncited”推断。
- `TeacherDoneEvent.citationStatus` 扩展为三值。
- `TalkMessage.citationStatus` 同。
- `TeacherMessage` 只在 `uncited` 时显示“没有标注来源”；`insufficient` 不显示这条警告，因为固定文案已经说明。

### 4.4 固定文案

新增 i18n（`teacherFallback`）：

```text
researchInsufficient
  中文：找到了一些资料，但来源不够可靠，这次先不据此下结论。你可以点开来源自己核对。
  英文：I found some material, but the sources are not reliable enough for a conclusion. You can open them and check for yourself.
```

- 由主进程 `translateFixedMessage` 读取，不经过模型。
- 语言跟随用户最新提问，不跟随 UI 语言。
- 文案不包含 `[n]` 引用，避免被误认为有引用。

### 4.5 UI

- 复用 `SourceList`。
- 消息以老师消息展示；不增加新组件。
- `citationStatus === 'insufficient'` 时不显示“没有标注来源”警告。
- 来源列表标题仍为“来源”；固定文案已经说明“仅供核对”。
- 点击来源仍走受控 `openExternal`。

### 4.6 兼容

- 正常有证据回答：行为完全不变。
- 0 条结果：仍走 `SEARCH_NO_RESULTS` overlay。
- 未配置/关闭搜索：行为不变。
- 旧的已存消息没有 `citationStatus`：按原推断逻辑处理。
- 不新增数据库列；只扩展 `companion_log` JSON。
- 不增加教学轮次。

## 8. 风险与边界

| 风险                        | 影响           | 处理                                                   |
| --------------------------- | -------------- | ------------------------------------------------------ |
| 展示低质量来源像“背书”      | 用户误信       | 固定文案明确“不足以下结论、仅供核对”；不生成断言       |
| 来源列表为空                | 空消息         | 只在 `evidence.length > 0` 时走该分支                  |
| `citationStatus` 旧数据缺失 | UI 误判        | 旧消息按原逻辑推断；新消息显式存                       |
| 固定文案语言错误            | 体验不一致     | 复用现有语言检测；中英文测试                           |
| 搜索错误携带大对象          | 内存/日志      | 只带来源元数据，不带全文 snippet                       |
| 误把 0 结果当证据不足       | 空列表         | `SEARCH_NO_RESULTS` 不带 evidence；分支要求 length > 0 |
| 写入失败                    | 用户看不到来源 | 走原有错误事件；不产生半截消息                         |
