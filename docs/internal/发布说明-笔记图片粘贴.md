## 1. 本次交付

- 新建/编辑念头支持在正文任意光标位置粘贴图片。
- 图片统一压缩为 WebP（最长边 2400、quality 0.9），存 `userData/images/<uuid>.webp`。
- 数据库新增 `pages.body_doc`、`page_images`、`page_image_refs`；图片与页面多对多引用。
- 卡片保留两行摘要，增加“含 N 张图”和“查看全文”；全文浮层只读展示文字/换行/图片；图片可点开 Lightbox。
- 草稿升级为 v2 `{ version, doc, source }`；旧 `{ body, source }` 自动转换。
- 图片随老师提问/恢复/维护/理解引导/联网问答/意图路由发送；相关旧念头/网页只发文字；标题/连接测试不发图。
- 发送前检测供应商图片能力：supported 才发；unsupported/unknown 自动纯文本；不提供强制发送。
- 设置页提供“自动检测 / 不发送”、能力状态、手动重新检测、7 天持久缓存和隐私说明。
- 导出改为目录：`backup.json` + `images/`，不含 base64。
- 清理：无引用图片 30 天、孤儿文件 7 天、临时文件 1 天；清空全部数据同时清空图片目录。

## 2. 数据与迁移

### 2.1 新增数据

```text
pages.body_doc              TEXT / TipTap JSON（{ version:1, doc }）
page_images                 id / file_name / mime / byte_length / created_at
page_image_refs             page_id / image_id（多对多）
userData/images/<id>.webp   图片文件
```

### 2.2 旧数据兼容

- 旧库启动时自动补 `body_doc`、创建图片表；旧页面仍按纯文本显示。
- 旧页面首次编辑时用 `docFromPlainText(body)` 迁移；保存后写 `body_doc`。
- 旧草稿 `{ body, source }` 在恢复时转成 v2 doc。
- 旧单 JSON 备份不做导入；新导出为目录 v2。旧备份请人工留档。

### 2.3 回滚警告

旧版本不认识 `body_doc` 与图片节点：

- 若用旧版本编辑含图念头，旧版本只改 `body`，`body_doc` 可能变旧；
- 回滚前先导出一次目录备份；
- 不要用旧版本编辑含图念头；如必须回滚，先确认备份可用。

## 4. 待手工验证（阻塞发布候选）

真实供应商的图片能力三态需要可用 Key：

| 场景                      | 期望                                     | 状态   |
| ------------------------- | ---------------------------------------- | ------ |
| 支持图片的模型            | 探测 supported；带图请求成功；回答正常   | 待验证 |
| 仅文本模型                | 探测 unsupported；纯文本请求；回答不中断 | 待验证 |
| `imageInput:'off'`        | 不探测、不发送；编辑器提示               | 待验证 |
| 429/网络/超时             | unknown；纯文本；短 TTL 重试             | 待验证 |
| 重启                      | 7 天内复用持久缓存                       | 待验证 |
| 清 Key / 改 model/baseUrl | 缓存失效，重新检测                       | 待验证 |

其他手工项：

- 中文 IME 组合输入、撤销/重做；
- 多图粘贴、超大图、窄屏；
- 从浏览器复制真实图片；
- 原生目录选择导出、清空数据、30/7/1 清理；
- 缺图/破图提示。

## 5. 已知问题

1. 供应商图片能力探测可能误判：极小的内置 WebP 被供应商拒绝时，会按 unsupported 纯文本处理；设置页可手动重测，不提供强制发送。
2. 动态 WebP 只保留首帧。
3. 草稿超过 30 天的图片可能被清理，草稿文字保留。
4. 4 个既有文件 `oxfmt --check` 不通过，本版未修改：
   - `wireframes/related-thoughts-rail.html`
   - `国际化文档.md`
   - `最小开发任务-长对谈上下文预算.md`
   - `高保真原型.html`
5. 本版不做导入、图片下载、图片裁剪/旋转、拖拽文件进窗口。
6. 真实供应商/原生目录对话框没有 E2E；分别由单测与手工覆盖。
