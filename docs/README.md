# 文档目录

仓库的文档按用途分开放置。`docs/` 下的内容以中文为主，属于项目内部资料；
对外的安装、配置和隐私说明以根目录的 [README](../README.md)、
[PRIVACY](../PRIVACY.md) 和 [CHANGELOG](../CHANGELOG.md) 为准。

## design/ — 设计、理念与架构

这些文档描述产品为什么这样设计、系统如何组织，以及提示词和文案的约定。

- [交互设计文档](design/交互设计文档.md) — 页面状态、引导面板、对谈与各种失败态。
- [技术架构文档](design/技术架构文档.md) — 进程边界、数据模型、IPC、检索、安全与隐私。
- [前端界面拆分](design/前端界面拆分.md) — 界面组件拆分与状态归属。
- [页面父子关系需求变更](design/页面父子关系需求变更.md) — 页面层级关系的需求调整。
- [提示词工程方案](design/提示词工程方案.md) — 引导、路由、研究与输出契约。
- [文案重构方案](design/文案重构方案.md) — 产品语言与界面文案的统一方案。
- [国际化文档](design/国际化文档.md) — i18n key、错误码与语言策略。
- [开发者模式提示词维护功能文档](design/开发者模式提示词维护功能文档.md) — 可编辑提示词的设计。
- [技术方案-笔记图片粘贴](design/技术方案-笔记图片粘贴.md) — 笔记文档模型与图片链路。
- [Prompt 评测工具使用文档](design/Prompt评测工具使用文档.md) — `tools/prompts/` 的使用说明。
- [高保真原型](design/高保真原型.html) — 早期界面原型（浏览器直接打开）。
