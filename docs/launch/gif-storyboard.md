# 演示录屏分镜 · TapAlong v0.1.0 alpha

> 目标：30–60 秒内让人看懂「它先回应、再追问，不代写」「旧念头会被接上来」「数据留在本机」。
> 成片：55 秒，12 镜，16:10 主版；另出 16:9、4:5 和 10 秒循环 GIF。
> 原则：只录真实运行，不补拍不存在的界面；演示数据全部自造。

## 4. 录制准备

1. **隔离数据**：用一个独立的 macOS 测试账户，或先备份 `~/Library/Application Support/TapAlong/` 再换测试目录。不要为了录屏删除真实数据。
2. **预置旧念头**：先确保没有「在聊」的念头（有就先收住），再写两条旧念头并「先想到这」，让第 5 镜有东西可接：
   - 「日程被切碎以后，注意力也跟着碎掉」——出处「日记」
   - 「带宽固定，但分配方式可以变」——出处「课程」
     两条都用演示数据，不复制任何真实笔记。
3. **模型**：配置一个可丢弃的 API Key，测试连接成功；录完在设置里清除 Key。不要用演示模式录主片——演示模式会显示「演示模式 · 未连接模型」和固定话术，容易让观众误以为真实能力如此。
4. **界面**：简体中文、浅色模式、窗口 1280×800（Retina 录制后缩到 1920×1200）；关闭通知、勿扰模式、隐藏桌面文件和其他窗口。
5. **画面**：不要出现 API Key、邮箱、姓名、真实书名以外的个人信息；不要出现浏览器标签、聊天窗口。
6. **表演**：鼠标移动慢，点击前停 0.3 s；输入可后期 1.5×；同一段录 2–3 遍，取最干净的一条。模型慢就剪等待，不要伪造界面。
7. **合规**：这是 alpha 录屏，界面会变；在视频简介里写明「演示数据，非真实用户笔记」。

## 5. 剪辑与压缩

**剪辑**

- 所有画幅都从**无字幕 master** 输出，再按画幅单独烧字幕；否则 16:9 裁切会切掉底部字幕。字幕也可以放在画面中部安全区。
- 先按 55 秒粗剪，确保第 4、5、6 镜不被切碎；这三镜承担“回应与追问 + 旧念头 + 用户决定”的叙事。
- 回应气泡和右侧栏用 1.1–1.2× 缓慢推近；不要频繁缩放。
- 转场只用硬切或 200 ms 淡入，不用花哨转场。
- 字幕在 1080p 下字号 32–40 px；手机竖屏版 44–52 px。

**MP4**

```bash
# 16:10 主版：直接缩放
ffmpeg -i tapalong-master.mov \
  -vf "scale=1920:1200:flags=lanczos" \
  -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p \
  -movflags +faststart -an tapalong-demo-55s-16x10.mp4

# 16:9：先放大再裁掉上下，避免左右黑边
ffmpeg -i tapalong-master.mov \
  -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080" \
  -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p \
  -movflags +faststart -an tapalong-demo-55s-16x9.mp4

# 4:5：上下补品牌底色，保留完整窗口
ffmpeg -i tapalong-master.mov \
  -vf "scale=1080:1350:force_original_aspect_ratio=decrease,pad=1080:1350:(ow-iw)/2:(oh-ih)/2:color=0xF7F3EC" \
  -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p \
  -movflags +faststart -an tapalong-demo-55s-4x5.mp4
```

**GIF（只做 8–10 秒循环，不要整段 55 秒）**

```bash
# 取第 5–6 镜（约 00:17–00:26），9 秒循环
ffmpeg -ss 00:17 -t 9 -i tapalong-master.mov \
  -vf "fps=12,scale=960:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128[p];[s1][p]paletteuse=dither=bayer:bayer_scale=3" \
  -loop 0 tapalong-loop.gif

# 超过 10MB 时：降到 800×500、10fps、7 秒，或减少颜色数
ffmpeg -ss 00:17 -t 7 -i tapalong-master.mov \
  -vf "fps=10,scale=800:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=96[p];[s1][p]paletteuse=dither=bayer:bayer_scale=3" \
  -loop 0 tapalong-loop-small.gif
```

验收：`du -h tapalong-loop.gif` ≤ 10 MB；MP4 主版目标 ≤ 10 MB（静态 UI 通常可做到；超了就降到 1600×1000 或 CRF 25，平台高清版可另存，但默认附件仍用 ≤10 MB 版）。GitHub README 里用 GIF，帖子/视频用 MP4。GIF 不要带声音，不要自动播放超过 10 秒。
